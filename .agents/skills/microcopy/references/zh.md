# 中文微文案参考

这是一个本地优先的助理工作台。中文文案要清楚、克制、可操作，让用户感觉自己仍然掌控运行、配置、权限和结果。

## 固定术语

- Agent process：运行时
- Local API/gateway：本地服务
- Conversation container：会话
- Long-running agent work：运行
- Tool/use progress：轨迹
- Provider credentials：模型服务商密钥
- App-owned config：应用管理的配置
- Native app bridge：桌面运行时

同一个概念只用一种说法。除非真的需要区分，不要在“运行时 / 进程 / 服务 / 后台程序”之间来回切换。

## 语气

- 短句优先。
- 先说明状态，再给下一步。
- 少用形容词，不写口号。
- 温度来自解释清楚和恢复掌控，不来自安慰话术。
- 不要求用户理解终端、配置文件或运行时细节。

## 按钮和动作

优先用“动词 + 对象”：

- 启动运行时
- 停止运行
- 重试
- 查看详情
- 打开诊断
- 复制日志
- 添加密钥
- 移除密钥
- 删除会话

能不用“确定 / 提交 / 继续”就不用。危险操作要说清对象。

## 空状态

```text
开始一个会话
描述你想做什么。
```

```text
还没有模型服务商密钥
添加密钥后，本地运行时就能使用你选择的模型服务。
```

## 等待和进度

```text
仍在运行。你可以先离开这个页面，稍后再回来。
```

```text
正在准备运行时...
首次启动可能需要一点时间。
```

## 错误

每条错误都要包含：

1. 发生了什么。
2. 用户接下来可以做什么。
3. 技术细节在哪里查看，如果有必要。

示例：

```text
本地服务还没有运行。
启动本地服务，或打开诊断查看详情。
```

```text
这次没有跑通。
你可以重试，或查看详情定位原因。
```

```text
密钥没有保存成功。
检查密钥后再试一次。已有密钥不会被修改。
```

## 权限和安全

语气中性、完整：

```text
允许访问文件夹
应用只会读取你在本次运行中选择的文件。
```

```text
密钥会保存在本地，并且只供这个运行时使用。
```

不要在常规界面里展示原始密钥、请求头、令牌或完整敏感路径。必要时放到诊断详情里。
